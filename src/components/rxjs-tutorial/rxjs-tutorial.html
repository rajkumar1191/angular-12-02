1. Higher-Order Mapping Operators

When an inner Observable is returned inside an outer stream we need a "flattening" operator. The four core flattening operators dictate how concurrency is handled.

switchMap

Cancels the previous request if a new one arrives. Best for Search/Typeahead.

mergeMap

Runs all inner streams in parallel concurrently. Best for disjoint bulk saves.

concatMap

Queues requests sequentially, waiting for one to finish before starting the next.

exhaustMap

Ignores all new requests while a current request is pending. Best for Login buttons to prevent spam.
