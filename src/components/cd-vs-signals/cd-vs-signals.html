Change Detection vs. Signals

Zone.js Tree-Walking vs. Fine-Grained Reactivity

🌳 Traditional (Zone.js)

Angular patches browser events (clicks, timers, XHR). When an event occurs, Angular walks the entire component tree from top to bottom, checking if any bound properties changed.

{{ traditionalValue }}

Use Cases:

  • Legacy codebases.
  • Simple apps where performance isn't a bottleneck.
  • When you rely heavily on RxJS async pipe (which manages CD for you).

🎯 Signals (Fine-Grained)

Signals create a direct dependency graph. When a Signal changes, Angular knows exactly which specific view needs updating, without checking unrelated components. This paves the way for Zoneless Angular.

{{ signalValue() }}

Use Cases:

  • Modern Angular 16+ apps.
  • Highly interactive or data-heavy views (dashboards).
  • Local component state and deeply nested components using compute().
