Services & Dependency Injection in Angular

1. Singleton Real-World Demo (Auth Service)

The AuthService is providedIn: 'root'. This means Angular creates exactly ONE instance and injects that same instance anywhere it's demanded. This is crucial for global state like authentication.

2. API Service & Injection Tokens

Services often wrap HttpClient to fetch data. We injected the API_BASE_URL token via the constructor. Injection Tokens are perfect for providing configuration objects or primitive values.

3. Shared State Management

Because SharedStateService is a Root Singleton, we can use RxJS Observables (like BehaviorSubject) within it to synchronize data across totally unrelated components seamlessly. Here, we increment a counter.

Global Counter: {{ sharedState.notificationCount$ | async }}

4. Dependency Hierarchy (Non-Singletons)

Services don't have to be singletons. By declaring providers: [LoggerService] inside the @Component(...) decorator of Child components, Angular creates a brand new instance of that service for every component initialized. Notice the Logger Instance IDs are different!
