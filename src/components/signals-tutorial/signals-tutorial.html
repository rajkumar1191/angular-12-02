Signals & Deferrable Views in Angular

Modern Reactivity using Angular v17+ Features

1. Signals (signal() & computed())

Signals represent state in Angular. A writable signal can be modified, while a computed signal automatically derives its value based on other signals without manual subscriptions.

2. Effects (effect())

An effect executes a side-effect function whenever one of the signals it reads changes. It is perfect for syncing data, logging, or interacting with non-Angular libraries. Play with the values above to trigger it!

4. Deferrable Views (\@defer)

Deferrable views allow you to lazily load portions of the UI (and the components they rely on) declaratively right in the template! This drastically reduces the initial bundle size. Let's load the to-do list below lazily.

@defer (on viewport) {
